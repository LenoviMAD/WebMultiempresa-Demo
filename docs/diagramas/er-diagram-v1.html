Regla de aislamiento: Solo las entidades marcadas TENANT tienen EmpresasExternaID. Las tablas hijo (ComboItems, ComboFechas, ComboVendedores, etc.) heredan el tenant via FK chain. EF Core aplica Global Query Filters automáticamente en los repositorios raíz.
