Licenciamiento multi-app:
TiposActores cataloga los actores del ecosistema (Vendedor, Fletero, Proveedor), cada uno ligado a su AplicacionID.
PlanCapacidades define cuantos actores de cada tipo permite un plan (N:M - sin columnas hardcodeadas). Un plan "Solo Ventas" tiene 1 fila. Un plan "Full SaaS" tiene 3 filas (Vendedor + Fletero + Proveedor).
Nuevos tipos de actor o nuevos planes se agregan con datos, sin cambios de schema.
Separacion de actores:
Usuarios = administradores web (JWT, rol Admin/SuperAdmin).
Vendedores = actores de la app Ventas (credenciales propias, sin acceso web).
Cada actor tiene sus propias credenciales. No comparten tabla ni sesion. UsuarioAppPermisos permite a un admin tener rol diferente en cada app.
Anti-patrones eliminados:
Productos.PrecioUnitarioFinalL1..L8 reemplazado por ProductoPrecios (N:M). Escala a cualquier cantidad de listas sin cambio de schema.
Clientes.VendedoresId1..4 reemplazado por ClienteVendedores (N:M). Sin limite de vendedores por cliente.
Clientes.ListaDePrecio (columna unica) reemplazado por ClienteListasPrecios (N:M con flag EsPrincipal).
GPS - diseno para alto volumen:
GPS_Posiciones usa BIGINT para el PK (millones de registros/dia). No tiene columna Baja (las posiciones nunca se borran logicamente). No aplica Global Query Filter (tabla particionada por mes - los filtros van en la query). Se discrimina por AplicacionID para soportar Vendedores y Fleteros en la misma tabla.
